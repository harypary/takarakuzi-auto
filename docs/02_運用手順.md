# 運用手順（セットアップと日常運用）

## 仕組みの全体像
```
GitHub Actions（cron）
  └ scripts/run_post.py --series numbers|loto6|loto7
      1. 当せん番号CSVを取得（loto-life / thekyo / mk-mode）→ data/results/*.json
      2. 週次学習：先週の各抽せんで6つの分析軸の成績を測り、重みを更新 → data/state/*.json
      3. 統計分析（出現頻度・インターバル・引っ張り・合計値・ペア・パターン…）
      4. 暦計算（六曜・九星・干支・節月・吉日・五行・数秘）
      5. 予想生成（本命4・対抗3・穴3。数字はPythonで決定的に計算）
      6. 先週の回顧（投稿済みの予想と結果の照合。公開前の週はバックテスト）
      7. 文章パーツ（Gemini。キーが無い／NG表現ならテンプレート文）
      8. NGワードチェック → カバー画像 → note に有料記事として投稿
      9. 予想記録を data/predictions/ に保存し、data をコミット
```

## 初回セットアップ（オーナー作業）

### 1. 宝くじ用 note アカウントのセッション保存
PowerShell で実行し、開いたブラウザで**宝くじ用アカウント**にログインします。
```powershell
cd C:\Users\haryp\game\31.takarakuzi
python scripts/setup_note_session.py
```
→ `output/note_session.json` ができます（git には含まれません）。

### 2. note 側の設定（ブラウザで手動）
- プロフィール（アカウント名・自己紹介に免責の一文を入れる）
- 特定商取引法に基づく表示の設定
- 有料記事の販売に必要な受取口座の設定

### 3. ローカルで1本だけ本番テスト
```powershell
python scripts/run_post.py --series loto7
```
投稿された記事を note で開き、有料エリアの位置・価格・ハッシュタグ・カバー画像を確認します。

### 4. GitHub リポジトリと Secrets
```powershell
gh repo create takarakuzi-auto --private --source . --push
[Convert]::ToBase64String([IO.File]::ReadAllBytes("output\note_session.json")) | gh secret set NOTE_SESSION_B64
gh secret set GEMINI_API_KEY      # 入力を求められたらキーを貼り付け（任意）
gh secret set NOTE_EMAIL          # セッション自動更新・再ログイン用
gh secret set NOTE_PASSWORD       # セッション自動更新・再ログイン用
```
- `SESSION_KEY`（セッション暗号化キー）は設定済み。毎月の更新で得たセッションは暗号化して `data/session/` にコミットされるため、GitHub の Personal Access Token は不要（期限切れなし）。
- 投稿時にセッションが切れていた場合も、NOTE_EMAIL / NOTE_PASSWORD でその場で再ログインして続行する。

### 5. Actions の手動確認
GitHub の Actions 画面で各ワークフローを `dry_run: true` で手動実行し、artifact の記事を確認します。

## 日常運用
| 曜日（JST） | 自動投稿 |
|---|---|
| 日〜木 21:30 | ナンバーズ3・4（翌日抽せん分） |
| 火・土 21:00 | ロト6（木・月抽せん分） |
| 水 21:00 | ロト7（金抽せん分） |
| 毎月10日 9:00 | note セッション更新 |

## よく使うコマンド
```powershell
# 生成だけ（投稿しない・学習状態も保存しない）
python scripts/run_post.py --series numbers --dry-run

# 基準日を指定して生成（翌日以降の最初の抽せん回が対象）
python scripts/run_post.py --series loto6 --today 2026-09-15 --dry-run

# テスト
python -m pytest -q
```

## 変更しやすい設定（src/config.py）
- `BRAND` / `MODEL_NAME`：アカウント名・モデル名
- `SERIES[...].price`：価格、`hashtags`：ハッシュタグ
- `DEFAULT_WEIGHTS`：分析軸の初期重み
- `PICK_TIERS` / `TIER_DESC`：本命・対抗・穴の口数と説明

## 既知の制約
- 九星（日盤）は閏の特殊処理を省略、六曜は中国暦で旧暦を近似（ごく稀に1日ずれる可能性）
- 当せん番号は第三者の公開CSVに依存。取得できない場合は保存済みデータで続行し、ログに警告
- 抽せんの時点で当日分がCSVに反映されていない場合、最大15分待って再取得してから続行
