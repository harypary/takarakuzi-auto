# 恋愛占いnote 自動投稿 ― 運用手順

12星座を「恋愛・人間関係」に絞って占い、noteに自動投稿する仕組み。
恋愛を主軸にしつつ、回ごとに暮らしのテーマ（仕事・人づきあい・お金・心と体・家族）を1つ添える。

## 商品とスケジュール

| いつ（JST） | 商品 | 価格 | 本数 | 対象期間 |
|---|---|---|---|---|
| 日曜 夕方〜21時台 | 星座別 週間恋愛運 | 980円 | 12本 | 翌週の月〜日 |
| 火・金 夕方〜21時台 | 12星座の恋愛運ランキング | 500円 | 1本 | その日から3日間 |
| 隔週木曜 夕方〜21時台 | 星座別 2週間の恋愛集中鑑定 | 1,980円 | 12本 | 翌週からの2週間 |
| 毎週日曜 5:00 | note セッション維持 | ― | ― | ― |

- 月およそ80本。定時実行は実測で5〜7時間遅れるため、14時台に予約して21時台の投稿を狙っている。
- 隔週の判定はスクリプト側（対象期間のISO週番号が偶数のときだけ投稿）。
- 同じ期間・同じ星座を二重投稿しないよう、`data/love_posts.json` に記録して照合する。

## 記事の作り方（何が自動で決まるか）

1. **暦** … 六曜・九星・干支・暦注の吉日（天赦日・一粒万倍日など）を計算（`src/koyomi.py`, `src/kyureki.py`）
2. **月相** … 新月・満月の日を天文計算で算出（`src/astro/moon.py`）
3. **恋愛運スコア** … 星座のエレメントを五行に変換し、日の五行・六曜・吉日・月相と重ねて1〜5を決定（`src/astro/love.py`）
4. **相性** … 同じエレメントと補い合うエレメントを高く評価（`src/astro/signs.py`）
5. **文章** … 上の事実データをGeminiに渡して長文を生成。キーがなければテンプレート文（`src/content/love_narrator.py`）
6. **記事** … 価格に応じた分量で組み立て（`src/content/love_article.py`）
7. **投稿** … カバー画像を作り、有料エリアの位置を確認してからnoteへ（`src/publishers/`）

数字・日付・星の数は必ず計算で決まる。Geminiは言葉だけを担当する。

## 初回セットアップ

### 1. note アカウントを作る（手作業）
恋愛占い用の新しいアカウントを作り、メールアドレスの認証まで済ませる。
有料記事を売るには、さらに次の2つが必要。
- 本人情報の登録（氏名・住所。初回の販売時に求められる）
- 特定商取引法に基づく表示と、売上の受取口座

### 2. セッションを保存する
```powershell
cd C:\Users\haryp\game\31.takarakuzi
python scripts/setup_note_session.py
```
ブラウザでログインし、最後の質問にEnterでGitHubへも反映（暗号化キーをSecretに登録し、暗号化セッションをpush）。

### 3. Secrets
| 名前 | 用途 |
|---|---|
| `SESSION_KEY` | セッションの暗号化キー（setup スクリプトが登録） |
| `GEMINI_API_KEY` | 文章生成（未設定ならテンプレート文で投稿） |

### 4. ブランド名
`src/love_config.py` の `BRAND` が記事タイトルとカバーに入る。アカウント名に合わせて変更する。

## よく使うコマンド

```powershell
# 生成だけ（投稿しない）
python scripts/run_love.py --product weekly --dry-run
python scripts/run_love.py --product summary --dry-run
python scripts/run_love.py --product intensive --dry-run --ignore-biweekly

# 1星座だけ試す
python scripts/run_love.py --product weekly --sign taurus --dry-run

# 日付を指定して試す
python scripts/run_love.py --product weekly --today 2026-10-18 --dry-run

# テスト
python -m pytest -q
```

## セッションが切れたとき
毎週日曜のワークフローが失敗し、GitHubから通知が届く。
`python scripts/setup_note_session.py` を実行してログインし直せば復帰する。

## 既知の制約
- noteのログイン画面にはreCAPTCHAがあるため、パスワードでの自動ログインは行わない（手動ログイン＋セッション維持方式）。
- 九星の閏の特殊処理は省略。六曜は日本時間の朔から計算し、公式の暦と一致することを確認済み。
- 投稿は1本あたり1分前後かかる。12本で20分ほど。
